فارسی و انگلیسی · آنلاین

وقتی دامنه Google یا Bing در دسترس نیست، Griffin تلاش می‌کند از موتورهای جست‌وجوی مستقل و منابع دانشنامه‌ای استفاده کند.

نکته: دسترسی به هر منبع به وضعیت شبکه و محدودیت‌های منطقه‌ای بستگی دارد. Griffin محدودیت شبکه را دور نمی‌زند؛ منابع جایگزین را امتحان می‌کند.
Griffin Search · مستقل از Google و Bing · جست‌وجو از منابع بیرونی دریافت می‌شود

تنظیمات و منابع جست‌وجو

منابع پیش‌فرض: DuckDuckGo برای وب و Wikipedia برای دانشنامه. این برنامه هیچ درخواستی به دامنه‌های Google یا Bing ارسال نمی‌کند.

افزودن SearXNG: یک نمونه شخصی یا مورداعتماد SearXNG راه‌اندازی کن، سپس آدرس پایه را در فایل .env با نام SEARXNG_URL قرار بده. Griffin آن را در کنار منابع دیگر امتحان می‌کند.

افزودن Brave Search: کلید API را فقط در فایل محلی .env و با نام BRAVE_SEARCH_API_KEY ذخیره کن. کلید را در GitHub یا کد مرورگر قرار نده.

بعد از تغییر فایل .env، سرور را یک‌بار خاموش و دوباره اجرا کن. نمونه تنظیمات در .env.example قرار دارد.

مستندات SearXNG · Brave Search API

درباره Griffin Search

Griffin Search یک رابط جست‌وجوی محلی و دوزبانه است که برای شبکه‌هایی طراحی شده که اتصال اینترنت دارند اما دسترسی به Google Search یا Bing ممکن نیست.

نتایج زنده از منابع مستقل می‌آیند؛ بنابراین اگر همه منابع جایگزین نیز در شبکه تو مسدود باشند، جست‌وجوی وب زنده ممکن نیست. برای پایداری بیشتر، SearXNG شخصی یا سرویس‌های معتبر جایگزین را پیکربندی کن.
